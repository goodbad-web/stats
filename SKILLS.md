# Skills

Use the smallest relevant skill or tool set for the task.

## SwiftUI / view work

- `build-ios-apps:swiftui-view-refactor`
  - Large view cleanup
  - Splitting body logic
  - Stabilizing state ownership

- `build-ios-apps:swiftui-ui-patterns`
  - Layout and interaction design
  - Navigation structure
  - Reusable SwiftUI component patterns

## Performance / stability

- `build-ios-apps:swiftui-performance-audit`
  - Excessive redraws
  - Slow rendering or scrolling
  - Unnecessary recomputation

- `build-ios-apps:ios-memgraph-leaks`
  - Retain cycles
  - Memory growth after navigation or repeated actions

## Build and debugging

- `build-ios-apps:ios-debugger-agent`
  - Simulator build, launch, logs, and runtime debugging

## GitHub work

- `github:github`
  - Repo, PR, and issue context

- `github:gh-fix-ci`
  - Broken GitHub Actions checks

- `github:gh-address-comments`
  - PR review feedback that needs code changes

## Rule of thumb

- Prefer one focused skill over several broad ones.
- Do not load unrelated skills just because they exist.
